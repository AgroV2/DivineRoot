DIVINE ROOT mod

Масштабный контент мод на Террарию в стилистике мрачного фэнтези, который направлен на:

> Переосмысление сеттинга ванильной Террарии;

> Упор на собственный лор и новую сюжетно-подвязанную прогрессию;

> Внедрение визуального нарратива;

> Добавление своего уникального контента и переработка множества ванильных механик.
